Menu bar icon & command palette states
Floating palette, 560 × 400, keyboard-first. Reference an artboard by its id badge (1b, 1d) in chat.
1a Menu bar icon — three concepts
Stacked pages
Three memory rows; the bottom one partially filled reads as “in use”. Most literal to RAM without being a chart.
16px: holds up — strokes stay 1px, fill row still legible.
Chip
Module with pins. Signals “hardware / system” and pairs well with a developer-tool identity.
16px: pins merge slightly — needs a 4-pin variant below 18px.
Allocation blocks
Four cells, one free. The filled ratio can animate with pressure — three filled at HIGH.
16px: strongest at small size — solid shapes, no hairlines.

1g Handoff notes
Type & spacing
SF Pro Text throughout; SF Mono for numbers, section headers and key hints so digits align. Body 13.5, query 15.5, section header 10.5 uppercase / .11em. Rows 38px (46px with a reason line), 10px side padding, 7px corner radius. Window padding 8px so selected rows inset cleanly.
Color
Chrome is neutral; color carries meaning only. Pressure pill: green / amber / red at one chroma. Quit borrows the red at 30–45% border, filled only on the selected row. Light mode flips ink to #1a1a1c on #fbfbfa with the same alpha ladder.
Window & focus
NSPanel, non-activating, .floating level, 13px radius, no titlebar. Height grows with content to a 480px cap, then the content area scrolls. Loses focus → closes. Search field keeps focus permanently; ↑↓ moves a selection index, so there is no visible caret move.
