A lightweight, native code editor for macOS.

Written in Swift and AppKit. Files, tabs, split editors, search, a command palette and a terminal, and Claude Code in that terminal sees what you select. No Electron, no web view, nothing running while you read.

$ curl -fsSL https://pulse0.app/install.sh | bash

An animated walkthrough: open a folder, ⌘P, autosave, project search, the terminal, per-area font sizes.

import AppKit

The parts of an editor you use every day.

func foldersAndTabs()

Open a project, browse it in the sidebar, keep many files open, with a path bar above each file. One window per folder (⇧⌘N). Folders load only when you expand them.

func splitEditor(_ direction: Direction)

Split right (⌥⌘\) or down from the tab’s right-click menu, for two files side by side or two places in one. A file open twice is still one copy of its text.

func highlight(_ language: Language)

Swift, TypeScript, Python, Go, Rust, C, Java, Kotlin, Ruby, shell, HTML, CSS, JSON, YAML, TOML, Markdown, SQL.

func searchProject(_ query: String)

The standard macOS find and replace bar in each file, and search across the project, using ripgrep when it’s installed. Files to include and exclude take globs, as in VS Code.

func commandPalette()

⌘P jumps to any file, ⇧⌘P runs any command, ⌘L goes to a line. Try ⌘P on this page.

lazy var terminal = TerminalPanel()

Your login shell in a panel under the editor, with tabs and side-by-side splits. Nothing is created until you first open it.

func sourceControl()

Changed files in the sidebar (⌃⇧G): stage or unstage them, or open one as a diff. Each refresh is one short git call, never a background poll.

func shareSelection(with: ClaudeCode)

Run claude in the terminal and it sees the file and lines you select, as in VS Code. ⇧⌘K sends the selection as an @-mention. Local only, and only if Claude Code is installed.

func autosave(after delay: TimeInterval = 1)

Files save a second after you stop typing. Quit any time: your folder, tabs and unsaved buffers come back.

func preferences()

Rebind any shortcut (⌥⌘K, or as JSON), size the editor, terminal and sidebar fonts separately, and pick light, dark or auto.

## How it stays small

Built so the memory doesn’t creep.

TextKit 1

One text view per pane

Switching tabs moves the pane’s layout engine onto another file’s text, so each extra file costs about the size of its text, not another editor. A split adds one view, and a file open in both panes keeps one copy of its text.

Temporary attributes

Highlighting without copies

Colors are drawing-time attributes, so highlighting never duplicates the document or triggers relayout. Large files are colored around what’s on screen.

Lazy

Everything on demand

The terminal, the go-to-file index, folder contents, a second editor pane and the Claude Code connection are created the first time you need them, not at launch.

0% CPU idle

Nothing ticking in the background

No polling, no animations, no indexers. The resource meter samples every two seconds only while Pulse is the active app, and the Claude Code connection just waits on a local socket.

# Questions

FAQ

Is Pulse a replacement for VS Code?

For a lot of everyday editing, yes. For extension-heavy workflows, no. Pulse has tabs, split editors, highlighting, find and replace, project search, a command palette, a terminal with tabs and splits, and a source control panel with diffs. It has no extensions, debugger, full Git client or built-in AI, and isn’t trying to.

Does it work with Claude Code?

Yes. Run claude in Pulse’s terminal and it sees the file and lines you select, the way it does in VS Code. ⇧⌘K sends the selection as an @-mention, and /ide connects a claude running in another terminal. The connection stays on your Mac, starts only if Claude Code is installed, and can be turned off with View › Share Selection with Claude Code.

Why install from Terminal instead of a download?

Pulse isn’t notarized by Apple yet, so macOS blocks a copy downloaded in a browser (“Apple could not verify ‘Pulse’…”). The installer fetches the same release with curl and clears that download flag, so Pulse opens normally. Updates from inside Pulse work the same way.

Does it support language servers or autocomplete?

Not yet. Language servers often use more memory than the whole editor, so if support arrives it will be optional and shown separately in the resource meter.

Why is the memory number different on my Mac?

Screen size, font size, the files you open and macOS version all change it. The status bar shows Pulse’s live footprint, and scripts/memory-check.sh runs the same scenarios as CI.

How do I report a bug or ask for a feature?

In Pulse, click the ladybug at the right end of the status bar, or choose Report a Bug… or Request a Feature… from the Help menu. Each opens a GitHub issue form in your browser (you need a GitHub account), and the bug form comes with your Pulse version, macOS version and Mac model filled in. You can also open an issue directly.

Does Pulse collect any data?

No. There is no telemetry, no analytics and no account. Pulse goes online only to check GitHub for a new release (at launch and at most once a day) and to download one when you choose to update. The Claude Code connection stays on your Mac.

# Privacy

Privacy

The Pulse app

Pulse collects nothing: no telemetry, no analytics, no account. It goes online only to check GitHub for a new release and to download one you choose to install.

Help › Report a Bug… opens a GitHub issue form in your browser with your Pulse version, macOS version and Mac model filled in, where you can see and change them. Nothing is posted until you submit the issue.

This website

If you click Accept in the cookie banner, this site loads Google Analytics 4, a service of Google. It sets two cookies, _ga and _ga_MCM9LLHVXG, which last up to two years, and records:

  • the pages and sections you view, how you arrived (the referring site) and when
  • your approximate location (country and city), browser, operating system, device type and screen size
  • when you click Copy on the install command

Google Analytics doesn’t store IP addresses. Google signals and ad personalization are turned off, and the data isn’t used for advertising. Google keeps it for two months.

If you click Decline, or don’t answer, Google Analytics doesn’t load and no cookies are set. Your answer is remembered in this browser’s local storage, on this device only.

at any time. Declining also deletes the Google Analytics cookies. Google also offers an opt-out browser add-on.

Hosting and fonts

The site is served by Cloudflare, and its fonts come from Google Fonts. Both receive your IP address when your browser loads the page, as part of delivering it.
