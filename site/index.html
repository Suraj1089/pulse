A code editor that stays under 100 MB.

Pulse is a native macOS editor written in Swift and AppKit. Files, tabs, search, a command palette and a terminal. No Electron, no web view, no extensions, nothing running while you read.

What’s inside

The parts of an editor you use every day.

Folders and tabs

Open a project, browse it in the sidebar, keep many files open. Folders load only when you expand them.

Syntax highlighting

Swift, TypeScript, Python, Go, Rust, C, Java, Kotlin, Ruby, shell, HTML, CSS, JSON, YAML, TOML, Markdown, SQL.

Find and project search

The standard macOS find and replace bar in each file, and search across the project, using ripgrep when it’s installed.

Command palette

⌘P to jump to any file, ⇧⌘P for every command, ⌘L for a line number.

Integrated terminal

Your login shell in a panel under the editor. It isn’t created until you first open it.

Autosave and recovery

Files save a second after you stop typing. Quit any time: your folder, tabs and unsaved buffers come back.

Left out, on purpose

Not missing. Left out.

Each of these is a reason other editors use hundreds of megabytes, run background processes, or slow down over time. Pulse is for the edits you make all day, not for replacing an IDE.

  • Extensions No extension host process
  • Git interface Use the terminal or your Git app
  • Debugger Use Xcode or your IDE
  • AI features None, and no account
  • Telemetry No network requests at all
How it stays small

Built so the memory doesn’t creep.

One text view for every tab

Switching tabs moves a single layout engine onto another file’s text, so each extra file costs about the size of its text, not another editor.

Highlighting without copies

Colors are drawing-time attributes, so highlighting never duplicates the document or triggers relayout. Large files are colored around what’s on screen.

Everything on demand

The terminal, the go-to-file index and folder contents are created the first time you need them, not at launch.

Nothing ticking in the background

No polling, no animations, no indexers. The resource meter samples every two seconds only while Pulse is the active app.

Questions

FAQ

Is Pulse a replacement for VS Code?

For a lot of everyday editing, yes. For extension-heavy workflows, no. Pulse has tabs, highlighting, find and replace, project search, a command palette and a terminal. It has no extensions, Git UI, debugger or AI features, and isn’t trying to.

Does it support language servers or autocomplete?

Not yet. Language servers often use more memory than the whole editor, so if support arrives it will be optional and shown separately in the resource meter.

Why is the memory number different on my Mac?

Screen size, font size, the files you open and macOS version all change it. The status bar shows Pulse’s live footprint, and scripts/memory-check.sh runs the same scenarios as CI.

Does Pulse collect any data?

No. There is no telemetry, no analytics, no account, and Pulse makes no network requests.

What happened to the Pulse memory monitor?

Pulse 2.0 replaces it with this editor, built on the same idea: native, small and quick. Version 1.x is still available on the releases page.
